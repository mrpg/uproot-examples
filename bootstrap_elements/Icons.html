Icons make pages faster to scan: a coin next to an amount, a clock next to a deadline, a check mark next to a correct answer. Bootstrap Icons contains more than 2,000 icons and ships with uproot, so no external requests are needed.

Loading and using icons

Load the stylesheet once in the head block. (In this app, Chapter.html does it for all chapters.) Then add an <i> element with the class bi and the class of the icon, which is bi- followed by its name on the icon website.

{% raw %}{% block head %}
<link rel="stylesheet" href="{{ internalstatic('vendor/bootstrap-icons/bootstrap-icons.min.css') }}">
{% endblock head %}

<i class="bi bi-coin" aria-hidden="true"></i> You receive $20.00.{% endraw %}

Size and color

Icons are characters of a font. They therefore take the size and color of the surrounding text, and every text class works on them: .fs-* for size, .fg-* for color. An icon inside a heading is as large as the heading.

Key classes: .fs-xs to .fs-6xl, .fg-primary, .fg-success, …, .fg-uproot (uproot)

Outline and filled variants

Many icons come in two versions: an outline and a filled one with the suffix -fill. The pair is a natural way to show state, for instance unselected and selected, or open and completed tasks.

Icons next to text

A small margin (.me-1 or .me-3) separates an icon from the following text. For longer, wrapping text, put both into a flex container, so that the text does not flow under the icon. Icons in buttons, badges, and alerts follow in later chapters.

Key classes: .me-1, .me-3, .d-flex, .gap-3, .flex-shrink-0

About 25 minutes

With .d-flex, a long text stays to the right of its icon when it wraps onto several lines. Without it, the second line would start below the icon, which looks untidy, especially on small screens.

Avatars

An .avatar is a circle that holds an image, initials, or an icon. Avatars are a neat way to show participants or roles. No image is needed, and a theme class can encode the role (always together with a label). .avatar-subtle uses lighter colors, and .avatar-sm, .avatar-lg, and so on change the size.

Key classes: .avatar, .avatar-subtle, .avatar-xs to .avatar-xl, .theme-*

Groups and status

In group experiments, an .avatar-stack shows the members of a group, and a status indicator (.avatar-status) shows who has already decided. The indicators differ in shape and color: .status-online is a green circle, .status-offline a gray square. Still, give each one a role="img" and an aria-label, and say in words what they mean.

Key classes: .avatar-stack, .avatar-status, .status-online, .status-offline, .status-busy, .status-away

Accessibility

Screen readers do not know what an icon means. If an icon is decorative, because the text next to it says the same, hide it with aria-hidden="true". If an icon carries meaning on its own, add a text alternative: role="img" with an aria-label, or a hidden text with .visually-hidden. Icon-only buttons need an aria-label.

Messages (decorative: aria-hidden="true")

Your answer: (meaningful: role="img" aria-label="correct")

(icon-only button: aria-label="Show help")
