Participants need to know where they stand: whether an answer was correct, how far along they are, and whether the page is waiting for something. Bootstrap’s feedback components answer these questions without words getting in the way.

Alerts

An alert is a colored box for a message. Its color carries a conventional meaning, so use it consistently: green for success, red for errors, yellow for warnings, and blue for neutral information. An icon reinforces the meaning for participants who cannot tell the colors apart.

Key classes: .alert with .alert-success, .alert-danger, .alert-warning, .alert-info, .alert-primary, .alert-secondary, .alert-light, .alert-dark

Additional content and dismissing

Alerts can contain headings (.alert-heading), paragraphs, and links (.alert-link gives links a matching color). .alert-dismissible adds room for a close button with data-bs-dismiss="alert"; with .fade .show, the alert fades out. A dismissed alert is removed from the page until it is reloaded.

Welcome back!

You left the study 10 minutes ago. Your answers so far have been saved.

Questions? Read the frequently asked questions.

Tip. role="alert" makes screen readers announce the message immediately. Use it for messages that appear in response to an action (like feedback after submitting), not for static text.

Callouts

uproot adds .callout, which turns an alert into a box with a thick left border. Callouts are quieter than alerts and suit hints, definitions, and examples within instructions. uproot itself uses alert alert-danger border-danger callout to show validation errors; this walkthrough uses callouts for tips and pitfalls.

Key classes: .alert .callout, optionally with .border-* for a stronger border color

Example. If you contribute $10 and the others contribute $30 in total, the group account contains $40.
Please answer this question. (This is how uproot shows errors.)

Badges

Badges are small labels: the current round, a treatment, a role, or a count of new messages. They scale with the surrounding text, so a badge in a heading is larger. .rounded-pill makes them round. A badge can also sit on the corner of a button, with a hidden text for screen readers.

Key classes: .badge with .text-bg-*, .rounded-pill; for positioning: .position-relative on the parent, .position-absolute .top-0 .start-100 .translate-middle on the badge

Progress bars

A progress bar shows a share: progress through the study, tokens spent, or time left. The outer .progress carries role="progressbar" and the aria-value* attributes; the inner .progress-bar gets its width as a style. Change the height with a style on .progress. Several bars in a .progress-stacked show how a total is composed.

Key classes: .progress, .progress-bar, .progress-stacked, .progress-bar-striped, .progress-bar-animated, .bg-*

Spinners

A spinner says “something is happening”: the page is waiting for another participant or for a response from the server. Spinners come as rotating borders or as growing dots, in any text color. Include a .visually-hidden text so that screen readers know what is going on.

Key classes: .spinner-border, .spinner-grow, .spinner-border-sm, .spinner-grow-sm, .text-*

Placeholders

Placeholders are gray blocks in the shape of the content that is about to appear. They are useful when content is loaded after the page, for example the order book of a market via live methods. .placeholder-glow or .placeholder-wave animate them; column classes set their widths.

Key classes: .placeholder, .placeholder-glow, .placeholder-wave, .placeholder-lg, .placeholder-sm, .col-*
