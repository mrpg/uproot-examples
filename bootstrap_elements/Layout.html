Layout decides where things go on the screen. Bootstrap’s layout tools are mobile first: you describe the layout for small screens and then add changes for larger screens. This matters for online experiments, where many participants use phones. The light-blue boxes in this chapter (.wt-cell) only make the otherwise invisible columns visible.

Containers

A container centers content and limits its width. You rarely need to add one yourself: uproot already wraps the main, main2, and main3 blocks in a .container, whose maximum width grows with the screen. For content that should span the whole window, such as a colored band, use the main_full_width block and put a .container inside to keep its text aligned with the rest of the page:

{% raw %}{% block main_full_width %}
<div class="bg-primary-subtle py-4">
    <div class="container">Full-width band with aligned text</div>
</div>
{% endblock main_full_width %}{% endraw %}

Key classes: .container, .container-fluid (always full width), .container-md (full width below the md breakpoint)

The grid

The grid divides a row into twelve columns. Put columns (.col, .col-*) directly inside a .row. Columns with plain .col share the space equally; .col-4 takes four of twelve columns; .col-auto is only as wide as its content.

Key classes: .row, .col, .col-1 to .col-12, .col-auto

Responsive breakpoints

Add a breakpoint to a class to apply it only from a certain screen width upwards. .col-12 .col-md-6 .col-lg-3 means: full width on phones, half width from tablets (md), and a quarter from laptops (lg). Resize your browser window to see the example below rearrange itself. Breakpoints work with most classes, not only with columns: .d-md-none, .text-lg-end, and so on.

Tip. Two options side by side on a laptop become two options stacked on a phone. Participants on phones may then see Option A long before Option B. If position matters for your design, test your pages on a phone (most browsers’ developer tools can simulate one).

Gutters

Gutters are the gaps between columns. Set them on the row with .g-0 to .g-5 (both directions), .gx-* (horizontal), or .gy-* (vertical, useful when columns wrap). .row-cols-* sets the number of columns per row on the row itself, which is handy for grids of cards.

Key classes: .g-*, .gx-*, .gy-*, .row-cols-*

Alignment, offsets, and order

Rows are flex containers, so they align columns with flexbox classes: .justify-content-* horizontally and .align-items-* vertically. .offset-md-2 leaves two columns empty, and .order-* changes the visual order.

Key classes: .justify-content-center, .align-items-center, .offset-*, .order-first, .order-last, .order-md-*

Flexbox and stacks

Not everything needs a grid. For a single line of items, use .d-flex with .gap-*; .ms-auto on an item pushes it (and everything after it) to the right. Stacks are shortcuts: .hstack is a horizontal, vertically centered flex row; .vstack a vertical one. .vr draws a vertical rule.

Key classes: .d-flex, .flex-wrap, .flex-column, .gap-*, .ms-auto, .hstack, .vstack, .vr

Spacing

Margin (m) and padding (p) classes follow one pattern: property, side, size. Sides are t (top), b (bottom), s (start, i.e., left), e (end, i.e., right), x (left and right), y (top and bottom), or nothing (all sides). Sizes go from 0 to 5; uproot adds 4-5 (2.25rem). .mx-auto centers a block with a set width.

Examples: .mt-3 (margin-top 1rem), .px-2 (horizontal padding 0.5rem), .mb-0, .p-4, .mx-auto

Sizing

Width classes set a width relative to the parent: .w-25, .w-50, .w-75, .w-100, and .w-auto. uproot adds .w-fit-content, which makes an element exactly as wide as its content. .mw-100 prevents an element from becoming wider than its parent. Heights work the same with .h-*; .h-100 is useful to give cards in a row equal height.

{% for width in [25, 50, 75, 100] %}
.w-{{ width }}
{% endfor %}

Aspect ratios

Embedded videos and iframes do not scale on their own. Wrap them in .ratio with .ratio-16x9, .ratio-4x3, .ratio-1x1, or .ratio-21x9, and they keep their shape at every width. The example uses a placeholder instead of a real video to avoid loading external content.
