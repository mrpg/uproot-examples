Tables are everywhere in experiments: payoff matrices in the instructions, history tables in repeated games, group results, and multiple price lists. Bootstrap styles tables only if you ask for it with .table, and modifier classes take care of the rest. uproot already uses tabular figures in table cells, so numbers line up in columns.

A basic table

Start with <table class="table"> and use <thead>, <tbody>, and, for totals, <tfoot>. Header cells (<th>) get a scope, which tells screen readers whether they describe a column or a row. A <caption> describes the table; .caption-top moves it above. Right-align numbers with .text-end, so that their digits line up.

Key classes: .table, .caption-top, .text-end, .table-group-divider

Striped, hover, bordered, and small

Modifier classes change how a table looks. They can be combined freely. Try them with the switches below; the class list underneath updates as you go. (The switches use Alpine.js, which uproot loads on every page, but the table itself is plain Bootstrap.)

  • .table-striped shades every other row, which helps the eye follow long rows. .table-striped-columns does the same for columns.
  • .table-hover highlights the row under the mouse pointer, which helps when reading across many columns.
  • .table-bordered adds borders on all sides of every cell; .table-borderless removes all borders.
  • .table-sm halves the cell padding for compact tables.
  • .table-card on a wrapper around the table gives it a rounded border, like a card.

Highlighting rows and cells

Theme classes color whole rows or single cells. In group results, highlighting the participant’s own row (plus a “You” badge, so the information does not depend on color alone) saves them from searching. .table-active works well for the current round.

Key classes: .theme-primary, .theme-success, .theme-danger, .theme-warning, .theme-info (on <tr> or <td>), .table-active, .align-middle

Payoff matrices

A payoff matrix is a table with headers on both axes. Center the cells, use .table-bordered so that each cell reads as one outcome, and distinguish the two payoffs within a cell by color and by position or label. .w-auto stops the table from stretching across the whole page.

Key classes: .table-bordered, .text-center, .align-middle, .w-auto, .table-responsive

Wide tables on small screens

A table with many columns, such as a multiple price list, does not fit on a phone. Wrap it in .table-responsive: the table then scrolls horizontally instead of breaking the page layout. .md:table-responsive and similar classes only scroll below a breakpoint. .text-nowrap keeps cells from wrapping. Make your window narrow to try it.

Key classes: .table-responsive, .md:table-responsive (and other breakpoints), .text-nowrap, .table-sm

Stacked tables

Instead of scrolling, a table can also turn each row into a block of its own on narrow screens. Add .md:table-stacked to the table and wrap it in .table-responsive: whenever the wrapper is narrower than the md breakpoint (768 px), the header disappears, the first cell of each row becomes its title, and every other cell shows its label from the data-cell attribute. Stacking only works with <td> cells, so the first cell is a <td> here, too. Make your window narrow to try it.

Key classes: .table-stacked, .md:table-stacked (and other breakpoints), .table-responsive
