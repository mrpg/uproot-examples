Utilities are single-purpose classes: one class, one effect. You have already used many of them (spacing, flexbox, text). This chapter covers the rest: colors, borders, shadows, visibility, positioning, and interaction. Together with components, they cover almost everything without custom CSS.

Colors

Bootstrap has eight theme colors. Each comes as text color (.text-*), background (.bg-*), background with a matching readable text color (.text-bg-*), and, since Bootstrap 5.3, as a subtle background (.bg-*-subtle), a subtle border (.border-*-subtle), and a strong text color for use on subtle backgrounds (.text-*-emphasis). uproot adds its own purple: .text-uproot, .bg-uproot, .bg-uproot-subtle, and .border-uproot.

Pitfall. Roughly one in twelve men of Northern European ancestry has some form of color vision deficiency, and red versus green is the most common confusion. Colors also carry connotations (red for loss or danger) that may act as an unintended treatment. Pair colors with text or icons, and keep color assignments constant across treatments unless color is the treatment.

Borders and corners

Add borders to all sides (.border) or single ones (.border-top, .border-start, …), and remove them with .border-0 or .border-top-0. Width goes from .border-1 to .border-5. Corners are rounded with .rounded, sized from .rounded-0 to .rounded-5, or shaped with .rounded-pill and .rounded-circle. uproot’s .rounded-0-1 gives almost sharp corners.

Display and responsive visibility

Display classes set how an element is laid out (.d-block, .d-inline, .d-flex, .d-grid) or hide it (.d-none). With breakpoints, they show content only on some screens: .d-md-none hides from tablets on, .d-none .d-md-block shows only from tablets on. This is useful for wording that depends on the device, like “tap” versus “click”. .d-print-none hides an element when printing.

Key classes: .d-none, .d-block, .d-inline-block, .d-flex, .d-*-none, .d-*-block, .d-print-none

Visually hidden content

.visually-hidden hides content from the screen but not from screen readers. Use it for labels that are obvious visually but not otherwise, such as the meaning of an icon. .visually-hidden-focusable shows the content when it receives keyboard focus; uproot uses it for the “Skip to main content” link at the top of every page (press Tab right after loading a page to see it).

3 out of 5 stars (screen readers announce “3 out of 5 stars”)

Position, overflow, and sticky elements

A box with a fixed maximum height and .overflow-auto scrolls on its own, for example a long list of items to rate. Inside it, .sticky-top keeps a header in view while the rest scrolls. (On the whole page, .sticky-top sticks to the top of the window.) Positioning classes (.position-relative, .position-absolute, .top-0, .start-100, .translate-middle) place elements precisely, like the badge on the chat button in the feedback chapter.

Key classes: .overflow-auto, .overflow-hidden, .sticky-top, .position-*, .top-*, .bottom-*, .start-*, .end-*, .translate-middle

Interaction

.user-select-all selects the whole text with one click, which is convenient for completion codes. .user-select-none prevents selecting text, for example the stimuli of a transcription task. .pe-none makes an element ignore the mouse, for example an illustration of a control that should not be operated.

Key classes: .user-select-all, .user-select-none, .user-select-auto, .pe-none, .pe-auto

Dark mode on a single element

Bootstrap 5.3 supports color modes. data-bs-theme="dark" switches an element and everything inside it to dark colors, including components. uproot pages use the light colors by default. A dark element can, for example, set a phase of the experiment apart or match a dark stimulus.

Customizing with CSS variables

Bootstrap’s components read their colors and sizes from CSS variables with the prefix --bs-. Override them in a style attribute (or in your own CSS) to customize a single element without fighting Bootstrap’s rules. uproot’s .btn-uproot is defined exactly this way. The variables of each component are listed in its documentation under “CSS”.
