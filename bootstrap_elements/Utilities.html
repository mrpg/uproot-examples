Utilities are single-purpose classes: one class, one effect. You have already used many of them (spacing, flexbox, text). This chapter covers the rest: colors, borders, shadows, visibility, positioning, and interaction. Together with components, they cover almost everything without custom CSS.

Colors

Bootstrap has eight theme colors: primary, accent, secondary, success, danger, warning, info, and inverse. Each comes as text color (.fg-*), strong text color (.fg-emphasis-*), background (.bg-*), lighter backgrounds (.bg-muted-* and .bg-subtle-*), and border color (.border-*, .border-subtle-*). On a solid background, .fg-contrast-* is the readable text color. Neutral grays come in steps: .fg-1 to .fg-4 for text and .bg-1 to .bg-4 for surfaces. .fg-50 and similar classes make a color translucent. uproot adds its own purple: .fg-uproot, .bg-uproot, .bg-subtle-uproot, .bg-muted-uproot, and .border-uproot.

Color pairs with theme classes

A theme class such as .theme-success on its own only selects a color. Add .theme-contrast (solid background, readable text), .theme-subtle, or .theme-muted (lighter backgrounds, darker text) to color any element at once, and .theme-border for a matching border. The pairs adapt to dark mode by themselves. This is the same mechanism that colors buttons, badges, and alerts.

Key classes: .theme-* with .theme-contrast, .theme-subtle, .theme-muted, .theme-border

Pitfall. Roughly one in twelve men of Northern European ancestry has some form of color vision deficiency, and red versus green is the most common confusion. Colors also carry connotations (red for loss or danger) that may act as an unintended treatment. Pair colors with text or icons, and keep color assignments constant across treatments unless color is the treatment.

Borders and corners

Add borders to all sides (.border) or single ones (.border-top, .border-start, …), and remove them with .border-0 or .border-top-0. Width goes from .border-1 to .border-5. Corners are rounded with .rounded, sized from .rounded-0 to .rounded-9, or shaped with .rounded-pill and .rounded-circle. uproot’s .rounded-0-1 gives almost sharp corners.

Shadows

Shadows lift an element off the page and draw attention to it. Use them sparingly, for the one element that matters most. A color class such as .shadow-primary tints a shadow.

Key classes: .shadow-none, .shadow-xs, .shadow-sm, .shadow, .shadow-lg, .shadow-xl, .shadow-* (colors)

Display and responsive visibility

Display classes set how an element is laid out (.d-block, .d-inline, .d-flex, .d-grid) or hide it (.d-none). With breakpoints, they show content only on some screens: .md:d-none hides from tablets on, .d-none .md:d-block shows only from tablets on. This is useful for wording that depends on the device, like “tap” versus “click”.

Key classes: .d-none, .d-block, .d-inline-block, .d-flex, .md:d-none, .md:d-block (and other breakpoints)

Visually hidden content

.visually-hidden hides content from the screen but not from screen readers. Use it for labels that are obvious visually but not otherwise, such as the meaning of an icon. .visually-hidden-focusable shows the content when it receives keyboard focus; uproot uses it for the “Skip to main content” link at the top of every page (press Tab right after loading a page to see it).

Position, overflow, and sticky elements

A box with a fixed maximum height and .overflow-auto scrolls on its own, for example a long list of items to rate. Inside it, .sticky-top keeps a header in view while the rest scrolls. (On the whole page, .sticky-top sticks to the top of the window.) Positioning classes (.position-relative, .position-absolute, .top-0, .start-100, .translate-middle) place elements precisely, like the badge on the chat button in the feedback chapter.

Key classes: .overflow-auto, .overflow-hidden, .sticky-top, .position-*, .top-*, .bottom-*, .start-*, .end-*, .translate-middle

Interaction

.user-select-all selects the whole text with one click, which is convenient for completion codes. .user-select-none prevents selecting text, for example the stimuli of a transcription task. .pe-none makes an element ignore the mouse, for example an illustration of a control that should not be operated. .hover-lift raises an element slightly on hover and keyboard focus, which signals that a card or tile can be clicked.

Key classes: .user-select-all, .user-select-none, .user-select-auto, .pe-none, .pe-auto, .hover-lift

Dark mode on a single element

Bootstrap supports color modes. data-bs-theme="dark" switches an element and everything inside it to dark colors, including components; add .bg-body and .fg-body to give the element itself the dark background and text color. uproot pages use the light colors by default. A dark element can, for example, set a phase of the experiment apart or match a dark stimulus.

Customizing with CSS variables

Bootstrap’s components read their colors and sizes from CSS variables with the prefix --bs-. Override them in a style attribute (or in your own CSS) to customize a single element without fighting Bootstrap’s rules. A theme class does nothing but set the --bs-theme-* variables, so a button needs only two of them for a color of your own; uproot’s .theme-uproot is defined exactly this way. The variables of each component are listed in its documentation under “CSS”.
